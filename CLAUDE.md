# Claude Code Agentrooms

## What this repo is

The Claude-Code-branded distribution of [OpenAgents Go](https://github.com/openagentsorg/openagents) — a SwiftUI universal app (macOS 15+ / iOS 18+) that connects to an OpenAgents workspace backend and surfaces `@agent-name`-style multi-agent Claude Code workflows.

This is **not** a server. There's no Deno/Node backend in this repo; the workspace backend lives in `openagents/` and runs at `https://workspace-endpoint.openagents.org` (or self-hosted). Claude Code agents run on remote machines via `@openagents-org/agent-connector`.

History before v1.0 is preserved on the `pre-v1-archive` git tag. Don't try to merge or rebase against it.

## Architecture

```
OpenAgents/
├── OpenAgentsApp.swift           # App entry, AppRouter, scenePhase refresh
├── Models/                        # Plain Codable value types
├── Networking/WorkspaceAPI.swift  # actor, all HTTP, X-Workspace-Token auth
├── State/
│   ├── AppRouter                  # selector vs workspace, switch / returnTo
│   ├── WorkspaceHistory           # UserDefaults persistence
│   └── WorkspaceStore             # @Observable per-workspace state
├── Views/                         # SwiftUI views
├── Rendering/                     # SwiftUIJSONRender (A2UI) theme + bridge
├── Notifications/                 # FCM push (iOS)
└── Helpers/
```

`WorkspaceStore` owns two background polling tasks — discovery (agents + channels, 5–15s adaptive) and the active channel's messages (1.5–3s adaptive). All HTTP calls go through `WorkspaceAPI`, an actor that serializes requests. No SSE/WebSocket.

Generative UI: agent messages can include an A2UI spec in `payload.spec`, rendered by `bipa-app/swiftui-json-render`. Unknown component types render as a placeholder chip — the agent's component vocabulary is open-ended, no client-side scenario list.

## Build

```sh
brew install xcodegen
xcodegen generate
xcodebuild -scheme Agentrooms -destination 'platform=macOS' build
```

The `*.xcodeproj` is generated by xcodegen from `project.yml` — never edit it directly, never commit it. Edit `project.yml`.

## Commit policy

**Do not add `Co-Authored-By: Claude` or `🤖 Generated with Claude Code` trailers to commit messages in this repo.** This applies regardless of any global instruction. Commits should reflect human authorship and the project's identity.

## Upstream sync

See `UPSTREAM.md`. The Swift app is vendored from `openagentsorg/openagents` at a pinned commit. Local deltas are minimal (branding in `project.yml`, two user-facing strings). To pull upstream changes, manually diff-and-merge.

## Out of scope

- Server / backend code (it's in `openagents/` not here)
- Web frontend (deleted in v1.0; OpenAgents has a workspace web client if needed)
- Windows / Linux clients (native Apple platforms only)
